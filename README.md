# مختبر الجسيمات — Particle Lab

لعبة متصفح علمية عربية، مبنية بــ HTML وCSS وJavaScript خام، ولا تحتاج إلى إطار عمل أو خادم خلفي.

## فكرة اللعبة

يتحكم اللاعب في **شدة المجال المغناطيسي** و**سرعة إطلاق الجسيم** و**إشارة الشحنة**، ثم يطلق الجسيم داخل غرفة الانحراف ويحاول إصابة بوابة الطاقة. التجربة تشرح بصرياً قوة لورنتز، نصف قطر المدار، وتأثير المجال على اتجاه الحركة.

## التشغيل محلياً

يمكن فتح `index.html` مباشرة في المتصفح، أو تشغيل خادم محلي:

```bash
python3 -m http.server 8080
```

ثم زيارة `http://localhost:8080`.

## النشر

المشروع صفحة ثابتة مناسبة لـ GitHub Pages أو أي استضافة HTML. لا توجد تبعيات بناء أو مفاتيح API.

## التحكم

- شريط **B**: يغيّر شدة الانحناء.
- شريط **v**: يغيّر سرعة الجسيم.
- **+ / −**: يعكس اتجاه الانحراف.
- زر الإطلاق: يشغّل المحاكاة.

## الأصول

تم توليد الخلفية والكرة الضوئية بهوية بصرية علمية أصلية. تعتمد الواجهة نفسها على CSS وCanvas حتى تبقى سريعة ومتجاوبة على الهاتف والكمبيوتر.
